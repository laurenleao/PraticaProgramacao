# Aula 02 - Desafios de Flexbox

Projeto desenvolvido para praticar conceitos de alinhamento, distribuição e responsividade em páginas web utilizando CSS Flexbox.

---

## Desafios Implementados

### 1. Menu Horizontal (`<nav>`)
* Alinhamento horizontal dos links de navegação.
* Espaçamento distribuído de forma uniforme.
* Centralização vertical e navegação por âncoras (`scroll-behavior: smooth`).

### 2. Galeria de Projetos (`.galeria-container`)
* Organização dos cards em linhas flexíveis com quebra automática (`flex-wrap: wrap`).
* Espaçamento uniforme (`gap`) e centralização do conteúdo.
* Layout em retângulos com cantos arredondados, gradientes e efeito hover.

### 3. Cartão de Perfil (`<aside>`)
* Estruturação vertical (`flex-direction: column`).
* Elemento de perfil circular (`border-radius: 50%`) alinhado ao centro.
* Botão de ação centralizado com transição suave no hover.

### 4. Layout Responsivo Completo (`<main>`)
* Estrutura semântica com `<header>`, `<main>`, `<aside>` e `<footer>`.
* Divisão em duas colunas na exibição desktop (conteúdo principal e sidebar).
* Configuração de Sticky Footer utilizando Flexbox.

---

## Tecnologias Utilizadas

* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização, layouts flexíveis (Flexbox), transições e responsividade.
