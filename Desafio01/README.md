# Atividade Prática - Formulário HTML com Validação Regex

Atividade desenvolvida para a disciplina de Desenvolvimento Web, abordando a criação de formulários em HTML5 e aplicação de expressões regulares (Regex) nativas através do atributo `pattern`.

## Tecnologias Utilizadas
- HTML5
- CSS3
- Regex (Expressões Regulares para validação nativa)

## Funcionalidades
- Validação de formato obrigatório diretamente pelo navegador (`required` e `pattern`).
- Organização dos campos por contextos utilizando `<fieldset>` e `<legend>`.
- Validação de documentos (CPF, CNPJ, RG, IE), e-mails corporativos, coordenadas de GPS e placa Mercosul.
